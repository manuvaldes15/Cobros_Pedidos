# Cobros Pedidos 🍔

Sistema de gestión de cobros y pedidos desarrollado con tecnologías modernas de frontend.

## **Descripción**

**Cobros_Pedidos** es una aplicación web diseñada para gestionar y administrar cobros de pedidos de manera eficiente. Proporciona una interfaz intuitiva para el seguimiento, procesamiento y control de transacciones comerciales.

## Stack Tecnológico

### Lenguajes
- **TypeScript** (97.1%) - Lenguaje principal del proyecto
- **CSS** (1.9%) - Estilos y diseño
- **HTML** (1%) - Estructura markup

### Tecnologías y Frameworks
- **React 19** - Librería para construir interfaces de usuario
- **Vite** - Herramienta de compilación y desarrollo ultra-rápida
- **Tailwind CSS 4** - Framework de CSS utility-first
- **TypeScript 5.7** - Tipado estático para JavaScript
- **Lucide React** - Librería de iconos
- **Node.js** - Entorno de ejecución (v22)

### Herramientas de Desarrollo
- **React DOM 19** - Renderizado de componentes en el DOM
- **OxFmt** - Herramienta de formateo de código
- **JPEG.js & PNG.js** - Procesamiento de imágenes
- **Vite Plugin React** - Plugin oficial de React para Vite

## Requisitos Previos

- **Node.js** >= 18.x
- **npm** o **yarn** (gestor de paquetes)

## Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/manuvaldes15/Cobros_Pedidos.git
cd Cobros_Pedidos
```

2. Instalar dependencias:
```bash
npm install
```

## Comandos Disponibles

```bash
# Iniciar servidor de desarrollo (disponible en http://localhost:5173)
npm run dev

# Compilar para producción
npm run build

# Previsualizar la compilación de producción
npm run preview

# Formatear el código
npm run format
```
